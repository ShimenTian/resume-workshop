# 简历工坊界面规格

当前产品为纯前端简历制作工具。使用者在浏览器中编辑简历，把可编辑文件保存在自己的电脑上，下次通过“打开文件”继续编辑。界面将浏览器暂存、电脑文件和 PDF 用途分别说明，不展示服务器同步状态。

首页与编辑器概念由内置 imagegen 生成，原始概念图为 `home-concept.png` 与 `editor-concept.png`，尺寸均为 1505×1045；完整提示词见 `prompts.json`。概念图用于布局和视觉参照，实际保存流程以本文规格为准。

## 视觉与布局

- 背景 #f6f7fb，纯白导航、表单与纸张；深海军蓝正文，#465fe9 主操作。
- 字体 PingFang SC / Microsoft YaHei / system-ui；首页标题 38px，章节 24px，正文 15px，控件 14px；边框 1px，圆角 8px。
- 首页：横向顶栏、居中 1180px 内容区、标题与说明、继续编辑横幅、筛选和搜索、三款真实排版简历预览，以及保存说明。
- 编辑器：约 60px 顶栏与 54px 工具栏，左侧 450px 表单，右侧灰色画布；A4 纸张默认按 75% 缩放。移动端提供内容/预览切换。
- 模板：经典简约、左右分栏、现代线条。各模板保持独立样式，共享同一份简历内容和主题配色。
- 图标：Lucide 轮廓，1.8px 描边，16–22px。标志为文档功能图标与文字。
- 按钮、导航、输入和折叠区域均为原生代码交互，模板缩略图使用真实简历组件。

## 内容与保存交互

“保存到电脑”和“打开文件”是主要文件入口。“保存到电脑”生成 `.resume.json`，保留正文、模板与配色；“打开文件”恢复可编辑内容。浏览器暂存帮助使用者继续当前编辑，电脑文件用于保留副本和在不同设备或浏览器间转移。

PDF 用于投递、打印和分享。导出说明提醒使用者同时保存可编辑文件，以便再次修改。文件保存成功、取消和失败分别反馈；浏览器不支持文件选择保存位置时，使用普通下载，并提供“普通下载”备用入口。

我的简历、使用指南、配色面板、导出说明与首页沿用同一套控件。支持模板筛选与搜索、创建、编辑、实时预览、模板与颜色切换、经历增删排序、复制、删除及撤销。示例人名、机构和成果均为虚构，不使用概念图中的内容充当用户资料。

## 运行与部署

默认通过 `npm run dev` 开发，`npm run build` 生成 `dist/`，`npm run preview` 检查构建结果。生产版本部署到静态网站即可，无需 Java、数据库或 API 代理。

页面采用 hash 路由，构建资源使用相对路径 `base: './'`，支持根目录与子目录静态托管。浏览器逻辑不上传简历。文件仅在使用者主动选择时读取，保存目标位于使用者自己的电脑。浏览器暂存按网站来源隔离，采用单编辑窗口流程。

此前的 Java 服务和 H2 数据保留为可选历史实现。Java 存储接口默认关闭，开启旧 API 需要显式配置；当前界面不依赖该接口。旧版默认服务器同步与“本机服务保存”的界面说明已由本地文件流程取代。

## 验证记录

最初界面实现已在桌面和 390×844 手机视口检查导航与标题层级、模板排列、编辑器双栏结构、字号、间距、配色、控件状态和横向溢出。预览与打印共享同一套文档组件，侧栏配色跟随主题色。

打印验证使用独立无界面 Chrome：三款示例均为 1 页 A4，三款分别加入 20 条经历后均为 4 页，文本提取确认条目完整。已修正全局页边距与文档留白叠加导致的多余分页。这是已有的打印验证记录；后续版式改动应重新检查实际分页。

当前前端测试覆盖文件校验、保存取消和失败、下载回退、文件往返、浏览器暂存异常，以及默认不请求服务器。Java 历史实现独立验证默认关闭接口和显式启用后的存储行为，不属于静态网站的运行依赖。

### 本地文件模式验收

- 30项前端自动化测试通过，构建通过；最大合法字段、三类经历各20条、中文与JSON控制字符转义均可完整保存并读取。
- 使用实际浏览器下载文件，在另一网站来源的空白浏览器存储环境中打开，确认内容、左右分栏模板与主题色恢复；继续修改后再次下载，与原始文件逐字段比对通过。
- 网络检查仅出现网页静态资源请求，编辑、打开文件、下载文件均无简历API请求；浏览器控制台无错误。
- 桌面1505×1045、手机390×844检查通过，保存弹窗与移动端编辑/预览正常，无横向溢出。
- 内置浏览器的下载事件等待接口超时，磁盘上的实际下载文件已确认并用于重新打开验证；文件选择器的取消、写入与关闭失败由自动化测试覆盖。
- 最终本地入口采用独立前端预览，Java服务已停止，旧实现与数据保留。
