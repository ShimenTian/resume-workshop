# 简历工坊 Java 服务（可选历史实现）

当前工具站采用纯前端运行方式，启动、构建和静态部署见 [项目 README](../README.md)。使用网站无需安装 Java、Maven 或数据库；前端开发及预览也不再将 `/api` 请求代理到 Java。

本目录保留此前的 Java 21 / Spring Boot 3.3.5 实现，供需要 Java 静态文件托管或原有本机 API 的场景选择使用。启动这个可选服务后，默认提供 `dist` 中的网站及健康检查，监听 `127.0.0.1:8081`。使用者在自己的电脑上打开、编辑和保存简历文件，浏览器也会暂存编辑内容。默认网页流程不上传简历到服务器。

默认配置为 `resume.storage.api-enabled=false`：简历存储接口未注册，相关请求返回 404；数据库连接和初始化也不会执行。已有的 `server/data/resumes.mv.db` 文件保留在原处，默认网站模式不会打开或修改这个简历库。

## 可选服务的启动与测试

先安装 JDK 21 或更新版本及 Maven 3.9。在项目根目录构建网页并启动服务：

```bash
npm run build
bash scripts/start-server.sh
```

然后访问 `http://127.0.0.1:8081`。启动脚本会切换到 `server` 目录，Java 服务由此读取 `../dist`。首次启动需要 Maven 下载依赖。修改前端后重新运行 `npm run build`，即可更新网站静态文件。

```bash
cd server
mvn test
mvn package
java -jar target/resume-workshop-server-0.1.0.jar
```

Java 版本由 Maven 使用的 `JAVA_HOME` 决定，可通过 `mvn -version` 查看。测试分别验证默认网站模式，以及显式启用的本机存储模式；存储测试使用临时数据库，与已有简历文件分开。

## 默认网站模式

`GET /api/health` 返回 `{"status":"ok"}`。`/api/resumes` 的查询、保存、删除和复制接口均未开放。网站可以通过反向代理提供 HTTPS 访问，前端构建产物也可以单独部署到静态网站托管服务。

用户保存到电脑的简历文件由用户自己管理，下次打开网站时可以重新打开文件继续编辑。浏览器暂存与当前浏览器及网站地址相关；换浏览器、清除网站数据或换域名时，应通过自己保存的文件恢复内容。服务器备份不包含这些用户文件。

## 可选的旧版本机存储模式

保留原有存储 API，供本机单人使用。需要时在 `server` 目录明确开启：

```bash
java -jar target/resume-workshop-server-0.1.0.jar --resume.storage.api-enabled=true
```

也可以通过环境变量 `RESUME_STORAGE_API_ENABLED=true` 配置。开启后才会初始化 H2，并读取 `server/data/resumes.mv.db`。当前网页默认仍使用电脑文件和浏览器暂存；开启此配置仅启用服务端接口，适用于已有的本机 API 客户端。

这一模式没有账户认证，也没有按用户隔离简历。请保持本机访问范围，避免将启用了存储 API 的服务对外发布。若要提供多人服务器存储，需要先实现身份认证和简历访问权限。

| 方法与路径 | 返回 |
| --- | --- |
| `GET /api/resumes` | 按更新时间倒序排列的 `ResumeDocument[]` |
| `PUT /api/resumes/{id}` | 新建或整体更新，返回保存的文档，状态码 200 |
| `DELETE /api/resumes/{id}` | 幂等删除，状态码 204 |
| `POST /api/resumes/{id}/duplicate` | 复制为新的 ID，名称追加「 · 副本」，返回文档，状态码 201 |

`PUT` 的 Content-Type 为 `application/json`。文档结构与 `../src/lib/resume.ts` 中的 `ResumeDocument` 一致，更新时需要发送完整文档。路径 ID 与文档 ID 必须一致，ID 仅支持 1–80 位英文字母、数字、下划线和连字符。更新时间使用带三位毫秒的 UTC ISO 字符串，例如 `2026-09-25T00:00:00.000Z`。列表中各条目 ID 在所属列表内唯一。

每份简历的每类经历最多 20 条，全库最多 50 份简历。姓名最多 80 字符、名称 100 字符、简介和经历描述 4000 字符、技能 2000 字符，其余字段限制与前端一致。所有文字字段均可暂时为空，以便保存编辑中的草稿。请求体最多 256,000 个 UTF-16 字符，编码后最多 1 MiB。JSON 的额外字段、重复键、尾随内容和错误日期均会被拒绝。

错误返回包含可显示给用户的 `error` 字段；非法内容返回 400，超大请求返回 413，简历数量达到上限返回 409，复制不存在的简历返回 404，数据库不可用返回 503。服务器不会通过错误响应输出异常堆栈。API 跨域仅允许 `http://localhost:5174` 和 `http://127.0.0.1:5174`。

备份旧版服务端简历库时，正常停止服务后复制 `server/data/resumes.mv.db`。再次启用本机存储模式后，服务会读取同一文件中的数据。
