# 简历工坊

一个纯前端简历制作工具。使用者在网页中编辑，将可编辑的简历文件保存在自己的电脑上，下次打开文件继续编辑。简历内容不上传服务器，无需登录。

项目使用 React、TypeScript 和 Vite。开发、构建及部署均无需 Java 或数据库；`dist/` 可直接交给静态网站服务器提供访问。

## 本地启动

需要 Node.js 22.18 或更新版本及 npm。在项目根目录运行：

```bash
npm install
npm run dev
```

默认打开 <http://127.0.0.1:5174>。如果端口已被占用，以终端显示的实际地址为准。开发服务器监听本机地址。

构建和预览发布版本：

```bash
npm run build
npm run preview
```

构建结果位于 `dist/`，预览地址同样以终端输出为准。运行预览前可先停止开发服务器，释放 5174 端口。`npm run preview` 用于本地检查构建产物，正式发布使用静态网站托管服务。

## 已实现

- 三种原创简历模板：经典简约、左右分栏、现代线条。
- 模板搜索与分类，空白新建或使用示例创建。
- 基本信息、工作、教育、项目、技能编辑，经历增删及排序。
- 实时 A4 预览、模板切换、主题配色、移动端编辑/预览切换。
- 保存到电脑：生成 `.resume.json` 可编辑文件，包含简历内容、模板和配色。
- 打开文件：恢复本站简历文件，也兼容旧版 JSON 备份。
- 浏览器自动暂存、草稿列表、复制、删除和短时撤销。
- PDF 打印导出，适合投递与分享。

模板中的人名、机构、经历与数据均为虚构示例。文件打开流程只读取用户主动选择的文件。

## 保存和继续编辑

1. 选择模板或点击“新建简历”，填写内容。
2. 点击“保存到电脑”，在弹窗中选择“普通下载”，保存例如 `张三的简历.resume.json` 的文件。
3. 下次访问网站，点击“打开文件”，选择保存的简历文件。
4. 继续编辑，完成后再次点击“保存到电脑”。

保存弹窗默认提供“普通下载”。支持文件保存对话框的浏览器还可点击“选择保存位置”。下载后请在下载列表确认文件保存成功。取消文件保存对话框不会发起下载。重新保存时，可在保存对话框选择原文件覆盖，或另存一份；普通下载可能生成带编号的新文件。

浏览器暂存不会自动更新电脑上的文件。暂存数据按网站来源隔离，即协议、域名和端口的组合；同一来源下的不同子路径共用浏览器存储。换电脑、换浏览器、换网站来源或清除网站数据后，可以用保存的文件恢复。当前按单编辑窗口设计，未提供跨窗口冲突合并。

电脑文件需要通过网站的“打开文件”读取；直接双击文件并不会自动启动本工具。当前版本暂不支持从 Word 或 PDF 恢复编辑。简历文件为普通 JSON，可包含姓名、联系方式等个人信息，请保存在自己信任的位置。文件大小上限为 2 MiB（2,097,152 字节），超出时会明确提示。

## 静态部署

先运行 `npm run build`，将 `dist/` 内的文件和目录完整上传到静态网站托管服务。托管配置为：

| 配置项 | 值 |
| --- | --- |
| 安装命令 | `npm install`，或在持续集成中使用 `npm ci` |
| 构建命令 | `npm run build` |
| 发布目录 | `dist` |
| 服务端运行环境 | 无 |
| API 代理、数据库、密钥 | 无需配置 |

`vite.config.ts` 使用 `base: './'`，构建后的 JS 和 CSS 路径相对于页面，因此同一份产物支持根目录和子目录，例如 `https://example.com/` 与 `https://example.com/tools/resume/`。子目录地址应以 `/` 结尾，让服务器提供该目录中的 `index.html`。

页面使用 hash 路由，例如 `#templates`、`#resumes` 和 `#edit/简历标识`。`#` 后的内容由浏览器处理，静态服务器无需配置 SPA 路由重写。编辑链接只标识当前浏览器中的草稿；把链接发给其他人不会传递简历内容，分享可编辑内容时应发送保存的简历文件。

建议提供 HTTPS，让支持文件保存对话框的浏览器可以使用相应功能；不支持时仍可通过普通下载保存。网站需通过 HTTP 或 HTTPS 访问，直接双击 `dist/index.html` 可能受到浏览器模块加载限制。当前仅完成本地构建与验证，尚未发布到公网。

## 检查

```bash
npm run build
npm test
```

前端测试覆盖文件校验、保存取消与失败、下载回退、文件往返、浏览器草稿与缓存异常，以及默认不发起网络请求。

## PDF 导出

编辑器中点击“导出 PDF”，在打印窗口选择“另存为 PDF”，纸张 A4、缩放 100%、关闭页眉页脚、开启背景图形。PDF 中的文字可选中。长内容自动分页，建议在打印预览中检查分页。需要下次继续编辑时，同时保存可编辑的简历文件。

## 保留的 Java 实现

`server/` 和已有的 `server/data/resumes.mv.db` 保留为可选历史实现，不参与默认的前端开发、测试或静态部署流程。Java 的简历存储接口默认关闭，原有本机 API 需显式启用，且尚无多用户身份认证和数据隔离。详情见 [server/README.md](server/README.md)。

此版本没有接入云端保存、AI 生成、支付或云账户。界面规格见 [design/DESIGN.md](design/DESIGN.md)。
